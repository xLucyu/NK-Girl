NK-Girl is an open source project i decided to first write in python together with a friend, since i was teaching him programming at the time.
However as time moved on i wanted to expand the bot and discord.js seemed like a better fit as i wanted to use react and 
learn more about typescript in general.

Connections:
- PostgreSQL Server
- Gsc Bucket
- Discord

To use this Bot, considering you have everything setup:
1. Copy it locally into your code editor
2. Install dependencies with npm install
3. Run schema.psql from the database directory 
4. Add your dependencies to the .env file 
5. Either type:
	- npm run dev
	- npm run build
	- npm run start

to start the bot, i hope the definitions make sense. You first need to build to start. dev runs independently.
